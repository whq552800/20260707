# Code publication note

The Word manuscript-generation script used during drafting is workstation-specific and is not part of the public analysis layer. Additional exploratory figure and parallel-analysis scripts that retained local absolute paths were also excluded from the public package. The public code directory contains the main environmental-domain profile script most relevant to reproducing the compound-profile outputs; paths may still need to be adapted to local data locations before rerunning.

The machine-readable CSV files in `tables/` are the authoritative tabular outputs for the submitted manuscript and Supplementary Tables S1-S6.
